# Blackout Widget

Настільний віджет для Windows, який показує графік відключень електроенергії
(джерело: <https://www.dtek-krem.com.ua/ua/shutdowns>). Віджет «прикріплюється»
до робочого столу, оновлює дані кожні ~15 хвилин, живе в треї та запускається
разом з Windows. Інтерфейс — українською. Жодних сторонніх сервісів і
телеметрії, крім сайту джерела.

## Розробка

```
npm i
npm run dev
npm test
npm run build
```

Перевірка джерела (smoke):

```
npx electron out/main/smoke-dtek.js
```

(спершу потрібен `npm run build`).

Перевірка типів: `npm run typecheck`.

Журнал роботи: `logs\app.log` у теці даних застосунку (Electron `userData`; під час розробки —
`%APPDATA%\blackoutwidget`), до ~1 МБ, попередній — `app.log.1`. Точний шлях показує вікно помилки запуску.
Туди пишуться помилки джерела, сирі поля поточного відключення з відповіді ДТЕК
і невідомі статуси годин.

## Збірка інсталятора

```
npm run dist:win
```

Результат: `dist/Blackout Widget Setup <версія>.exe` (NSIS, x64, встановлення для
поточного користувача без прав адміністратора).

## Перше встановлення на Windows

Інсталятор не підписаний, тому Windows SmartScreen покаже попередження.
Натисніть «Докладніше» → «Виконати все одно».

Автозапуск вмикається лише в зібраній (встановленій) версії й керується в
налаштуваннях застосунку.

## Як додати нове джерело

1. Реалізуйте інтерфейс `ScheduleProvider` (див. `src/main/providers/types.ts`)
   у `src/main/providers/<id>/`.
2. Зареєструйте провайдера в `src/main/providers/registry.ts`.
3. Додайте фікстури й тести за зразком `dtek-krem`.

## Фактичний стан (EcoFlow)

Окрім графіка ДТЕК, віджет може показувати, чи світло є насправді: він читає
станцію EcoFlow через офіційний Open API (лише читання) і за напругою на вході
AC визначає, чи є мережа.

**Ключі.** Подайте заявку на <https://developer-eu.ecoflow.com/> («Become a
Developer»). Її розглядають вручну, це може тривати кілька днів. Коли доступ
схвалять, там же створіть Access Key і Secret Key.

**Куди вводити.** Налаштування → Фактичний стан світла. Ключі зберігаються
зашифрованими засобами ОС (Windows DPAPI); якщо шифрування недоступне, вони не
зберігаються взагалі.

**«Невідомо».** Означає, що застосунок не знає стан: станція офлайн, немає
інтернету або хмарні дані застаріли. У такому разі «Світла немає» ніколи не
показується.

**Обмеження.**

- Підтримка River 2 через Open API не підтверджена. Якщо під час «Перевірити»
  з’являється помилка `1006`, EcoFlow не віддає цю станцію через API розробника.
- Якщо роутер не живиться від станції, під час відключення стан буде
  «невідомо»: інтернету немає, і застосунок не бачить станцію.
- EcoFlow дозволяє ~10 різних MQTT clientId на добу для акаунта. Застосунок
  використовує один сталий clientId на установку.

**Живий smoke-скрипт** (потрібен `npm run build`; ключі — зі змінних середовища,
регіон `eu` за замовчуванням, `us` за потреби):

```
$env:ECOFLOW_ACCESS_KEY = "..."
$env:ECOFLOW_SECRET_KEY = "..."
$env:ECOFLOW_REGION = "eu"
npx electron out/main/smoke-ecoflow.js
```

Перевірка триває близько 2 хв. Скрипт друкує маску Access Key і список станцій.
Для кожної станції він двічі, з проміжком щонайменше 60 с, запитує `quota/all`
і друкує вердикт мережі, назви всіх ключів показів (значення — лише для ключів входу AC), сирі значення
`inv.acInVol` / `plugInInfoAcInVol` (щоб звірити, мілівольти це чи вольти) і
назви ключів, що змінилися між двома запитами. Якщо не змінилося нічого, скрипт
прямо про це попереджає: тоді за самим `quota/all` свіжість даних не визначити.
Далі він 60 с слухає MQTT і друкує коди QoS із SUBACK (128 — брокер відмовив у
підписці), чи позначене перше повідомлення `/quota` як retained, кількість
повідомлень за хвилину, чи надсилає MQTT ключі входу AC, які є в `quota/all`, і
вердикт після злиття. Нічого не пише на диск і не публікує в MQTT. Він
використовує одноразовий clientId `BlackoutWidget-smoke`, що теж зараховується в
ліміт ~10 clientId на добу. Код виходу: 0 — успіх; 1 — помилка, відмова в
підписці, в акаунті немає станцій або жодна станція не віддала `quota/all`.

Запустіть скрипт, коли світло є, і ще раз під час справжнього відключення: так
видно, що саме станція показує, коли мережі немає.

## Відомі обмеження

- Окремі шпалери на різних моніторах не підтримуються.
- При перетягуванні віджета між моніторами з різним масштабом (DPI) вміст може
  масштабуватися неправильно до перезапуску. Запасний шлях — пункт
  «Перемістити віджет» у треї.
- Результати інтерактивної перевірки прикріплення ще очікуються
  (кліки/перетягування/Win+D).
